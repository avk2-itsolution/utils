# Чек-лист проверки КП

## Бизнес

- [ ] Понятно, что не устраивает заказчика сейчас.
- [ ] Понятно, что изменится для пользователя.
- [ ] Нет неподтвержденных обещаний.
- [ ] Технические детали не заменяют описание результата.

## Архитектура

- [ ] Определен источник истины.
- [ ] Различены перенос и синхронизация.
- [ ] Указано направление обмена.
- [ ] Определены сущности Bitrix24.
- [ ] Описаны связи между сущностями.
- [ ] Решено, где штатный Bitrix24, backend и UI.
- [ ] Нет лишних смарт-процессов.

## Оценка

- [ ] Общие работы вынесены отдельно.
- [ ] Нет двойной оценки сервера, смартов и тестирования.
- [ ] Модуль не оценивает повторно данные другого модуля.
- [ ] Детализация равна итогу.
- [ ] Все итоговые суммы пересчитаны.
- [ ] Неопределенность вынесена в обследование или условия.

## Документ

- [ ] Есть краткое резюме.
- [ ] Каждый модуль начинается с пользовательского результата.
- [ ] Есть общая архитектура.
- [ ] Есть итоговая таблица.
- [ ] Есть ограничения и исключения.
- [ ] Страницы не перегружены.
- [ ] Word отрендерен и визуально проверен.
