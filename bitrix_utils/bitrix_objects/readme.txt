Удобные шорткаты для Битрикс объектов

Подмодули:

catalog — сущности каталога (товары, разделы, инфо-блоки, единицы измерения) и их менеджеры.
crm — сущности CRM (лиды/сделки/смарт-процессы/справочники/товарные позиции) + базовые менеджеры.
tasks — задачи и группы задач.
users — пользователи портала и базовый класс.
groups — рабочие группы/проекты портала.
departments — подразделения портала.
lists — списки Bitrix24.
main — инфраструктура (базовый объект/менеджер/список/поля/исключения).
utils — утилиты (файлы, мультимультиреквизиты).

Общие принципы:
- Все сущности наследуются от BitrixObject (main) и имеют менеджер .objects().
- CRUD/list идут через but.call_api_method/call_list_method с валидацией ответов в менеджерах (_validate_api_*).
- Поля описаны через классы из main.fields (TextBitrixField, ObjectBitrixField, и др.), многие отмечены is_required=True.
- BitrixObjectList — итерируемый список объектов, поддерживает загрузку select_related.
